# Number Club gameplay reference

## 2. Book ladder

A Book changes the board, target, and any stated starting economy for all 27
Puzzles. An Obstacle is chosen separately and changes only the solving tools.
Nothing carries between Books except the persistent sequential unlock.

| Book | Givens: easy / medium / boss | Target multiplier | Starting coins |
| --- | --- | --- | --- |
| 1 — You've Got This, Probably | 41 / 35 / 29 | 1.00× | 5 |
| 2 — Slightly Harder, Sorry | 38 / 32 / 26 | 1.00× | 5 |
| 3 — No Pressure, Obviously | 38 / 32 / 26 | 1.25× | 5 |
| 4 — This One Bites | 35 / 29 / 23 | 1.50× | 3 |

Book 2 is the first published step of this ladder. Books 3 and 4 are specified
here but remain locked until their dedicated implementation tickets land.
